# Historical archive

This directory preserves provenance, not the current setup guide.

- `development/`: original append-only implementation, verification and research
  notes, including states that were pending at the time and later superseded.
- `m1/`: early parser/packet-walk learning milestones and environment records.
- `../decisions/`: original architectural decision records retained for context.

Old workstation paths, container names, test counts and status statements are
historical. Start with the [current documentation](../README.md) and
[verified results](../results.md). Keeping these records avoids erasing failures
or negative experiments while removing them from the repository's main reading path.
